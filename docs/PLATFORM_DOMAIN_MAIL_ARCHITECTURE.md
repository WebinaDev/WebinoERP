# مستند جامع معماری سرویس ایمیل دامنه، DNS و وب‌میل ماژول Platform

این مستند معماری، ساختار جداول پایگاه داده، رکوردهای امنیتی (SPF, DKIM, DMARC)، و جریان ساخت صندوق‌های پستی سازمانی (**Domain Email**) در ماژول **Platform** سامانه **WebinoERP** را تبیین می‌کند.

---

## ۱. چرخه کامل هویت دامنه و ایمیل سازمانی

در معماری جدید، دامنه فقط یک آدرس وب ساده (Web URL) نیست، بلکه هویت جامع شرکتی شامل **میزبانی وب + صندوق‌های ایمیل + احراز هویت DNS** است:

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    Webino Platform: Domain Identity & Email                 │
└──────────────────────────────────────┬──────────────────────────────────────┘
                                       │
 1. ثبت دامنه در پلتفرم                │ PlatformDomain (webinoerp.com)
                                       ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ 2. راه‌اندازی زیرساخت ایمیل دامنه (`PlatformMailDomain`)                       │
│    • تولید جفت کلید نامتقارن RSA-2048 جهت امضای DKIM                         │
│    • تولید رکورد SPF: `v=spf1 mx a:mail.webinoerp.com ~all`                  │
│    • تولید رکورد DKIM: `default._domainkey.domain`                           │
│    • تولید خط‌مشی DMARC: `v=DMARC1; p=quarantine; rua=...`                   │
│    • تخصیص سرور MX با اولویت ۱۰                                             │
└──────────────────────────────────────┬──────────────────────────────────────┘
                                       │
 3. اعتبارسنجی زنده رکوردهای DNS        │ `DomainMailService@checkDnsStatus`
                                       ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ 4. ایجاد و مدیریت صندوق‌های پستی (`PlatformMailbox`)                          │
│    • ایجاد صندوق‌های رسمی: `info@`, `sales@`, `support@`, `ceo@`             │
│    • تعیین سهمیه دیسک (Quota)، کلمه عبور ایمن (bcrypt)، و نام نمایشی        │
│    • مدیریت نام‌های مستعار و فورواردینگ (`PlatformMailAlias`)               │
│    • پاسخگوی خودکار مرخصی و عدم حضور (Out-of-Office Auto Reply)             │
└──────────────────────────────────────┬──────────────────────────────────────┘
                                       │
 5. وب‌میل داخلی و پروتکل‌های خارجی    │ IMAP / SMTP & Webmail UI
                                       ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ 6. دسترسی به ایمیل‌ها                                                        │
│    • وب‌میل سبک داخلی سازمانی (`PlatformWebmailMessage`)                    │
│    • اتصال از Outlook، Thunderbird یا موبایل از طریق IMAP/SMTP امن          │
└─────────────────────────────────────────────────────────────────────────────┘
```

## ۲. رکوردهای ضروری DNS و فرمت استاندارد

| نوع رکورد | هاست (Name) | مقدار (Value) | اولویت / توضیحات |
| :--- | :--- | :--- | :--- |
| **MX** | `@` | `mail.webinoerp.com` | اولویت: `10` (هدایت ایمیل‌های ورودی به میل‌سرور) |
| **TXT** | `@` | `v=spf1 mx a:mail.webinoerp.com ~all` | رکورد SPF جهت جلوگیری از جعل فرستنده (Anti-Spoofing) |
| **TXT** | `default._domainkey` | `v=DKIM1; k=rsa; p=MIIBIjANBgkqh...` | کلید عمومی RSA-2048 جهت اعتبارسنجی امضای دیجیتال ایمیل‌ها |
| **TXT** | `_dmarc` | `v=DMARC1; p=quarantine; rua=mailto:...` | خط‌مشی پذیرش، قرنطینه یا رد ایمیل‌های نامعتبر |

## ۳. اندپوینت‌های وب‌سرویس مدیریت ایمیل دامنه

- **`GET /api/v1/platform/mail/domains`**: دریافت فهرست دامنه‌های دارای سرویس ایمیل همراه با شمارش صندوق‌ها.
- **`POST /api/v1/platform/mail/domains/setup`**: فعال‌سازی ایمیل برای دامنه، تولید خودکار کلیدهای DKIM و رکوردهای DNS.
- **`POST /api/v1/platform/mail/domains/{mailDomain}/check-dns`**: کوئری و بررسی زنده وضعیت انتشار رکوردهای MX و SPF روی DNSهای جهانی.
- **`GET /api/v1/platform/mail/domains/{mailDomain}/mailboxes`**: دریافت لیست صندوق‌های پستی دامنه با حجم مصرفی و سهمیه.
- **`POST /api/v1/platform/mail/domains/{mailDomain}/mailboxes`**: ساخت صندوق پستی جدید (`info@domain`) با کنترل سهمیه و رمز عبور.
