# مستند جامع چرخه عمر قراردادها و امضای دیجیتال (Contract Lifecycle Management - CLM)

این سند فرآیند، متدهای اعتبارسنجی ماشین حالت (State Machine)، طرف‌های قرارداد، اقساط، متمم‌ها و امضای الکترونیک امن با پیامک یکبارمصرف (OTP) در ماژول **Docs** سامانه **WebinoERP** را تبیین می‌کند.

---

## ۱. ماشین حالت چرخه عمر قرارداد (Contract State Machine)

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ 1. پیش‌نویس اولیه حقوقی (`draft`)                                            │
└──────────────────────────────────────┬──────────────────────────────────────┘
                                       │ تکمیل مبالغ و طرفین
                                       ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ 2. بررسی داخلی و ارزیابی حقوقی/مالی (`internal_review`)                      │
└──────────────────────────────────────┬──────────────────────────────────────┘
                                       │ تایید مدیران
                                       ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ 3. ارسال به طرف دوم / مذاکره (`sent` / `customer_review` / `negotiation`)   │
└──────────────────────────────────────┬──────────────────────────────────────┘
                                       │ توافق نهایی
                                       ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ 4. ایجاد پاکت امضای دیجیتال و ارسال پیامک OTP (`pending_signature`)          │
└──────────────────────────────────────┬──────────────────────────────────────┘
                                       │ تایید هویت و اعتبارسنجی رمز
                                       ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ 5. امضای رسمی و قفل سند حقوقی (`signed` & `is_locked = true`)                │
│    • ثبت زمان دقیق، IP امضاکننده، مشخصات دستگاه و تولید گواهی SHA-256       │
└──────────────────────────────────────┬──────────────────────────────────────┘
                                       │ فرارسیدن تاریخ شروع
                                       ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ 6. قرارداد فعال، پیگیری اقساط و ثبت الحاقیه‌ها (`active` & Addenda)          │
└─────────────────────────────────────────────────────────────────────────────┘
```

---

## ۲. جداول تخصصی CLM

- **`docs_contracts`**: مدل اصلی با فیلدهای شماره یکتای قرارداد، شناسه معامله CRM، شناسه پروژه، مبلغ کل، تاریخ شروع و پایان، وضعیت قفل و دلیل فسخ.
- **`docs_contract_parties`**: تفکیک حقوقی طرف اول (کارفرما/مجری)، طرف دوم (مشتری/پیمانکار) و ضامن به همراه شناسه ملی، کد اقتصادی، شماره ثبت و کد پستی.
- **`docs_contract_installments`**: جدول اقساط و تاریخ‌های سررسید با پیوند به فاکتورهای فروش ماژول `Sales`.
- **`docs_signature_envelopes`**: پاکت‌های امضای دیجیتال با هش رمزنگاری‌شده OTP و گواهی الکترونیک امضا.
- **`docs_contract_addenda`**: الحاقیه‌های متمم قرارداد (تغییر مبلغ، تمدید زمانی، تغییر دامنه کار) با اعمال مستقیم روی قرارداد مادر و افزایش شماره نسخه.

---

## ۳. اندپوینت‌های وب‌سرویس

- **`POST /api/v1/docs/contracts/{contract}/transition`**: انتقال ایمن وضعیت قرارداد طبق قواعد ماشین حالت.
- **`POST /api/v1/docs/contracts/{contract}/envelopes`**: ساخت پاکت امضا و ارسال OTP پیامکی.
- **`POST /api/v1/docs/envelopes/{envelope}/sign`**: اعتبارسنجی رمز یکبارمصرف و قفل قطعی سند حقوقی.
- **`POST /api/v1/docs/contracts/{contract}/addenda`**: صدور الحاقیه رسمی و اصلاح خودکار مقادیر قرارداد مادر.
