# مستند درگاه سخت‌افزار عملیاتی و تجهیزات فروشگاه/انبار (Webino Device Gateway)

این سند فرآیند، معماری عامل محلی (Agent)، درایورهای سخت‌افزاری، پروتکل جفت‌سازی امن با شعبه و انبار و آزمون چاپ مستقیم در سامانه **WebinoERP** را تشریح می‌کند.

---

## ۱. چرخه اتصال درگاه سخت‌افزار (Device Gateway Edge Loop)

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ 1. کلاینت وبینای مستقر در مرورگر کاربر (WebinoERP Frontend)                 │
└──────────────────────────────────────┬──────────────────────────────────────┘
                                       │ ارسال فرامین چاپ و پرداخت (WSS Localhost:18080)
                                       ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ 2. عامل محلی ویندوز/لینوکس/مک (Webino Device Gateway Rust Core)             │
│    • احراز هویت جفت‌سازی با شعبه/انبار (`dev_gateways`)                      │
│    • مدیریت صف فرامین و ارسال بسته‌های باینری                                │
└──────────────────────────────────────┬──────────────────────────────────────┘
                                       │ درایورهای مستقیم پورت‌های USB/LAN/Serial
                                       ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ 3. تجهیزات و ادوات عملیاتی لبه (`dev_peripherals`)                           │
│    ├─ PC-POS Terminals : کارتخوان سامان‌کیش (SEP) و سپهر با استاندارد شتاب    │
│    ├─ Label Printers   : چاپ مستقیم کدهای ZPL روی پرینترهای زبرا انبار       │
│    ├─ Receipt Printers : صدور فاکتور حرارتی ۸۰ میلی‌متری با پروتکل ESC/POS   │
│    └─ Barcode Scanners : اسکنرهای بارکدخوان خطی و دوبعدی QR                  │
└─────────────────────────────────────────────────────────────────────────────┘
```

---

## ۲. جداول تخصصی ماژول DeviceGateway

- **`dev_gateways`**: گیت‌وی‌های ثبت‌شده به تفکیک شرکت، شعبه و انبار با نگهداری پلتفرم سیستم‌عامل و هارت‌بیت زنده.
- **`dev_peripherals`**: تجهیزات جانبی متصل با تعریف نوع سخت‌افزار، مدل، پروتکل اتصال (USB/Network/Serial) و کانفیگ اختصاصی.
- **`dev_print_jobs`**: صف فرامین چاپ بارکد، فیش و رسید انبار با ذخیره پی‌لودهای خام ZPL/ESC-POS و وضعیت تحویل.

---

## ۳. رابط کاربری فرانت‌اند (`frontend/src/features/modules/device-gateway/index.tsx`)

- **شاخص‌های عملکردی (KPIs)**: تعداد تجهیزات آنلاین، وضعیت آمادگی کارتخوان پوز بانکی، وضعیت لیبل‌پرینتر و آپ‌تایم ایجنت محلی.
- **تب تجهیزات و درایورها**: جدول جامع ادوات متصل با شناسه پورت و آدرس‌های IP شبکه.
- **تب آزمون چاپ و تراکنش فوری**: ارسال مستقیم دستور خام ZPL به پرینتر لیبل و تست تراکنش کارتخوان بدون درایور ویندوز.
- **تب وضعیت ایجنت و Pairing**: کلید جفت‌سازی اختصاصی، شعبه منتسب و پروتکل ارتباطی WSS.
