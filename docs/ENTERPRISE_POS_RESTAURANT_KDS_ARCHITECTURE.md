# مستند جامع معماری پایانه فروش، رستوران و KDS (Webino POS & Restaurant Suite)

این مستند تشریح‌کننده اهداف، نقش‌ها، رابط‌های کاربری لمسی و تعاملی، فرآیند ثبت سفارش زیر ۱۰ ثانیه، نمایشگر آشپزخانه (KDS)، سفارش‌گیری سر میز (Waiter) و تطبیق نقدینگی شیفت در سامانه **WebinoERP** است.

---

## ۱. چرخه عملیاتی نقش‌های رستوران و فروشگاه

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ 1. مشتری / گارسون (Customer QR / Waiter Tablet)                            │
│    • اسکن منوی دیجیتال یا سفارش لمسی سر میز                                  │
│    • ثبت اقلام، افزودنی‌ها و یادداشت آماده‌سازی                              │
└──────────────────────────────────────┬──────────────────────────────────────┘
                                       │ ارسال بی‌درنگ (Real-Time WebSocket / API)
                                       ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ 2. نمایشگر آشپزخانه (Kitchen Display System - KDS)                          │
│    • کارت‌های زنده به تفکیک زمان سپری‌شده (سبز → زرد → قرمز)                │
│    • تفکیک ایستگاه‌ها: آشپزخانه گرم vs بار نوشیدنی                           │
│    • اعلام وضعیت: شروع آماده‌سازی → آماده سرو ✓                              │
└──────────────────────────────────────┬──────────────────────────────────────┘
                                       │ فراخوانی جهت تسویه یا تحویل
                                       ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ 3. پایانه صندوقدار (Cashier POS)                                            │
│    • ثبت سفارش لمسی کمتر از ۱۰ ثانیه                                        │
│    • اتصال مستقیم به کارتخوان‌های بانکی شتابی (SEP PC-POS)                  │
│    • اتصال به کشوی نقد (Kick Pulse) و چاپگرهای حرارتی ۸۰ میلی‌متری           │
│    • تسویه و خروج فاکتور رسمی                                                │
└──────────────────────────────────────┬──────────────────────────────────────┘
                                       │ پایان شیفت کاری
                                       ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ 4. تطبیق کشوی نقدی و بستن روز (Cash Drawer Audit)                           │
│    • مقایسه موجودی فیزیکی واقعی با رقم انتظاری سیستم (فروش نقدی + اولیه)    │
│    • ثبت مغایرت‌ها و ارسال گزارش به حسابداری و داشبورد مدیر                  │
└─────────────────────────────────────────────────────────────────────────────┘
```

## ۲. نقش‌های عملیاتی هفت‌گانه

1. **صندوقدار (Cashier)**:
   - رابط لمسی (Touch-First)، منوی دسته‌بندی‌شده سریع با کلیدهای بزرگ، سبد خرید زنده.
   - تسویه با یک کلیک کارتخوان بانکی سامان‌کیش یا نقد با باز شدن خودکار کشو.
2. **مدیر (Manager / Owner)**:
   - دید ۳۶۰ درجه عملیاتی، فروش ساعتی، نرخ اشغال میزها، و نظارت بر هشدارهای موجودی بحرانی مواد اولیه.
3. **آشپزخانه (KDS)**:
   - کارت‌های رنگی بزرگ، زمان‌سنج آماده‌سازی، تفکیک استیشن‌های بار و غذا.
4. **گارسون (Waiter)**:
   - تبلت پرتابل با نقشه سالن و ثبت سفارش سر میز و درخواست صورتحساب به صندوق.
5. **پیک (Delivery)**:
   - مأموریت‌های تحویل بیرون‌بر به تفکیک مقصد و زمان سفر.
6. **حسابدار (Accountant)**:
   - تفکیک مالی نقد، کارتخوان، تطبیق کسری/فزونی صندوق و گزارش سود ناخالص.
7. **مشتری (Customer)**:
   - سفارش از طریق اسکن کد QR روی میز، پیگیری وضعیت زنده فاکتور و پرداخت آنلاین.

---

## ۳. صفحات و مسیرهای فعال در داشبورد ERP

- **`sales/pos`**: هاب جامع پایانه فروش و رستوران با تب‌های صندوق، KDS، مدیر، گارسون و شیفت.
- **`sales/pos/cashier`**: کنسول اختصاصی لمسی صندوقدار.
- **`sales/pos/kds`**: صفحه مانیتور آشپزخانه تمام‌صفحه.
- **`sales/pos/tables`**: مانیتورینگ سالن، تراس و میزهای VIP.
- **`sales/pos/shift`**: گزارش و فرآیند بستن شیفت و کشوی نقد.
