# پایپ‌لاین انتشار و توزیع ماژول‌های مارکت‌پلیس (Git / Gitea / Release Distribution)

این سند فرآیند استاندارد، مکانیزم‌های سخت‌گیرانه اعتبارسنجی قرارداد پکیج، امضای دیجیتال، لاگ حسابرسی (Audit) و توزیع ایمن پکیج ماژول‌ها در **WebinoERP** را تبیین می‌کند.

---

## ۱. چرخه کامل پایپ‌لاین توزیع (Build → Validate → Checksum → Publish → Entitlement)

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ 1. تگ‌گذاری و انتشار در مخزن Gitea (`git tag v1.2.0 && git push`)           │
└──────────────────────────────────────┬──────────────────────────────────────┘
                                       │ Webhook / Fetch Archive
                                       ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ 2. دریافت و ذخیره در فضای ایزوله مارکت‌پلیس (`crm_build` package)             │
└──────────────────────────────────────┬──────────────────────────────────────┘
                                       │
                                       ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ 3. اعتبارسنجی سخت‌گیرانه قرارداد پکیج (`ReleaseDistributionValidator`)         │
│    • وجود فایل `manifest.json` در ریشه                                      │
│    • وجود فایل بوت‌استرپ `bootstrap.php`                                    │
│    • بررسی بیلد فرانت‌اند `client/dist/module.js`                            │
│    • تطابق نسخه هسته (`requires_core_min`)                                  │
└──────────────────────────────────────┬──────────────────────────────────────┘
                                       │ در صورت عبور موفق از قرارداد
                                       ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ 4. محاسبه Checksum امنیتی SHA-256 و اندازه دقیق بایت‌ها                     │
│    • ثبت روی `marketplace_releases.checksum_sha256`                         │
│    • ثبت روی `marketplace_releases.package_size_bytes`                      │
└──────────────────────────────────────┬──────────────────────────────────────┘
                                       │
                                       ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ 5. ثبت لاگ حسابرسی انتشار (`marketplace_distribution_audits`)               │
│    • کاربر منتشرکننده، آدرس IP، هش SHA-256 و هشدارهای بیلد                 │
└──────────────────────────────────────┬──────────────────────────────────────┘
                                       │
                                       ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ 6. توزیع و نصب امن روی سایت مقصد (`SiteModuleInstall`)                       │
│    • بررسی لایسنس و توکن موقت دانلود (`MarketplaceLicenseService`)           │
│    • تطابق هش SHA-256 قبل از اکسترکت و جلوگیری از تغییر فایل (Anti-Tamper)  │
│    • نصب اتمیک، اکسترکت و فعال‌سازی امن                                     │
└─────────────────────────────────────────────────────────────────────────────┘
```

## ۲. مشخصات قرارداد فایل پکیج توزیع (ZIP Contract)

| مولفه | وضعیت | نقش و کاربرد |
| :--- | :--- | :--- |
| **`manifest.json`** | **اجباری (Fatal)** | شناسنامه ماژول، نام یکتا (slug)، نسخه معنایی (SemVer) و حداقل نسخه هسته ERP |
| **`bootstrap.php`** | **اجباری (Fatal)** | راه‌انداز سرویس‌ها، رجیستر کردن روت‌ها و هندلرهای هسته |
| **`client/dist/module.js`** | **هشداردهنده (Warning)** | باندل بیلدشده جاوااسکریپت برای بارگذاری در منوها و فرانت‌اند داشبورد |
| **`includes/`** | اختیاری/پیشنهادی | پوشه کدهای پشتیبان، کتابخانه‌ها و کنترلرها |

---

## ۳. امنیت و ممانعت از انتشار کور (Anti-Blind Release)

پیش از این، انتشار صرفاً با کلیک روی دکمه publish و بدون بازرسی فایل انجام می‌شد؛ اکنون در صورت فقدان فایل‌های الزامی یا خرابی آرشیو ZIP، فرآیند فوراً با خطای ۴۲۲ متوقف شده و خطاهای ساختاری به همراه هشدارهای کلاینت به مدیر نمایش داده می‌شوند.
