# مستند جامع هوش تجاری و تصمیم‌سازی مدیریتی (Business Intelligence - BI)

این سند فرآیند، معماری انباره داده و جداول رویداد/فکت، شاخص‌های کلیدی عملکرد (KPI)، داشبوردهای نقش‌محور و سیستم هشدارهای آستانه‌ای (Early-Warning Alerts) در سامانه **WebinoERP** را تشریح می‌کند.

---

## ۱. لایه‌های تصمیم‌سازی در BI

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ 1. لایه ثبت رویدادها و اسناد عملیاتی (Transactional Domain Events)           │
│    • Sales Invoices, CRM Deals, Scm Stock Ledger, FSM Work Orders, etc.     │
└──────────────────────────────────────┬──────────────────────────────────────┘
                                       │ انتقال به لایه تجمیع و فکت‌ها
                                       ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ 2. انباره داده و جداول فکت (Fact Tables & Dimensions)                        │
│    • Facts: `fact_sales`, `fact_payments`, `fact_support_sla`, etc.         │
│    • Dimensions: `dim_date`, `dim_company`, `dim_customer`, `dim_product`   │
└──────────────────────────────────────┬──────────────────────────────────────┘
                                       │ موتور تحلیل و ارزیابی آستانه
                                       ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ 3. داشبورد مدیرعامل و اتاق‌های تصمیم‌گیری (Executive Cockpit & War Rooms)     │
│    ├─ Executive Cockpit : درآمد MoM، حاشیه سود، جریان نقدی، سلامت هلدینگ    │
│    ├─ Sales War Room    : قیف تبدیل لید تا قرارداد و وصول وجه               │
│    ├─ Finance Aging     : جدول سنی مطالبات (0-30, 31-60, 61-90+)            │
│    └─ Ops Early-Warning : هشدارهای کسری موجودی، نقض SLA و انقضای قرارداد    │
└─────────────────────────────────────────────────────────────────────────────┘
```

---

## ۲. جداول تخصصی ماژول BI

- **`bi_subscriptions`**: اشتراک گزارش‌های دوره‌ای زمان‌بندی‌شده (روزانه، هفتگی، ماهانه) با صدور خودکار CSV/JSON برای مدیران ارشد.
- **`bi_threshold_alerts`**: قوانین مانیتورینگ هوشمند آستانه‌ها (`metric_key`: low_stock, expiring_contracts, sla_breaches, high_ar_aging) با دیسپچ اعلان‌های فوری در صورت عبور از خط قرمز.

---

## ۳. رابط کاربری فرانت‌اند (`frontend/src/features/modules/bi/index.tsx`)

- **کارت‌های شاخص‌های کلیدی عملکرد (KPIs)**: درآمد تحقق‌یافته ماه جاری، رشد ماهانه (MoM)، حاشیه سود ناخالص عملیاتی، ارزش پایپ‌لاین جاری معاملات و درصد پایبندی به SLA خدمات.
- **تب داشبورد مدیرعامل (Cockpit)**: ترکیب درآمدهای هلدینگ به تفکیک کانال، جریان نقدینگی خالص و شاخص گردش کالا (Turnover).
- **تب اتاق جنگ فروش (Sales War Room)**: جدول قیف کامل تبدیل لیدها، معاملات، پیش‌فاکتورها و قراردادهای وصول‌شده.
- **تب سنی مطالبات (Accounts Receivable Aging)**: تفکیک فاکتورهای سررسیدنشده، معوقات ۳۱-۶۰ روز و مطالبات پرریسک ۶۱-۹۰ روز.
- **تب هشدارهای آستانه و ریسک عملیاتی**: هشدارهای قطعات یدکی بحرانی، نقض تعهدات زمانی و قراردادهای در آستانه انقضا.
