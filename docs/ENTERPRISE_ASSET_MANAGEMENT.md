# مستند جامع ماژول دارایی‌های ثابت و نگهداری (Fixed Asset Management - AM)

این سند فرآیند، شناسنامه اموال، کارت استقرار و تحویل‌گیرنده، استهلاک دوره‌ای حسابداری، نگهداری پیشگیرانه (PM) و پوشش بیمه‌ای در سامانه **WebinoERP** را تبیین می‌کند.

---

## ۱. چرخه عمر دارایی‌های ثابت (Asset Lifecycle)

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ 1. خرید کالای سرمایه‌ای و صدور کارت دارایی (`ast_assets`)                   │
└──────────────────────────────────────┬──────────────────────────────────────┘
                                       │ تخصیص کد پلاک، محل فیزیکی و امین اموال
                                       ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ 2. استقرار و آغاز بهره‌برداری (`status=active`)                             │
│    • ثبت بهای تمام‌شده خرید، ارزش اسقاط و تعیین دوره عمر مفید (ماه)         │
└──────────────────────────────────────┬──────────────────────────────────────┘
                                       │ محاسبه پایان دوره مالی
                                       ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ 3. اجرای خودکار استهلاک دوره‌ای (`ast_depreciation_runs`)                   │
│    • روش خط مستقیم: `(بهای خرید - ارزش اسقاط) / عمر مفید`                   │
│    • صدور خودکار سند روزنامه در دفترکل: بدهکار هزینه استهلاک / بستانکار استهلاک انباشته │
│    • به‌روزرسانی ارزش دفتری خالص روز (Book Value)                            │
└──────────────────────────────────────┬──────────────────────────────────────┘
                                       │ فرارسیدن موعد سرویس
                                       ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ 4. نگهداری پیشگیرانه و تعمیرات (`ast_maintenance_orders`)                    │
│    • صدور خودکار دستورکارهای PM، چک‌لیست‌های کالیبراسیون و ثبت هزینه‌ها     │
└──────────────────────────────────────┬──────────────────────────────────────┘
                                       │ پایان عمر مفید
                                       ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ 5. اسقاط، فروش یا تجدید ارزیابی با صدور سند مالی تسویه خروج                 │
└─────────────────────────────────────────────────────────────────────────────┘
```

---

## ۲. جداول تخصصی ماژول Assets

- **`ast_assets`**: مدل اصلی کارت دارایی شامل کد پلاک یکتا، عنوان، دسته، شعبه، محل استقرار فیزیکی، امین اموال، بهای خرید، ارزش دفتری خالص و حساب‌های معین مالی.
- **`ast_depreciation_runs`**: دوره‌های محاسبه استهلاک ماهانه با ثبت مجموع ارقام و شناسه سند روزنامه حسابداری.
- **`ast_maintenance_plans`**: طرح‌های نگهداری پیشگیرانه دوره‌ای (ماهانه، فصلی، سالانه).
- **`ast_maintenance_orders`**: دستورکارهای تعمیر و نگهداری با ثبت هزینه‌های قطعه و دستمزد.
- **`ast_insurances`**: بیمه‌نامه‌های فعال اموال و تجهیزات جهت پوشش ریسک‌های حوادث و شکست ماشین‌آلات.

---

## ۳. رابط کاربری فرانت‌اند (`frontend/src/features/modules/assets/index.tsx`)

- **شاخص‌های کلیدی عملکرد (KPIs)**: ارزش ناخالص دفتری دارایی‌ها، ارزش دفتری خالص روز، دستورکارهای فعال PM و درصد پوشش بیمه‌نامه‌ها.
- **تب دفتر اموال**: جدول کارت‌های دارایی با کد پلاک، امین اموال، محل استقرار و وضعیت بهره‌برداری.
- **تب استهلاک دوره‌ای**: دفتر دوره‌های استهلاک و سندهای حسابداری قطعی‌شده.
- **تب نگهداری و تعمیرات (PM)**: مدیریت دستورکارهای سرویس دوره‌ای تجهیزات صنعتی و سرورها.
- **تب بیمه‌نامه‌ها**: رهگیری شرکت بیمه‌گر، سقف پوشش ریالی و تاریخ سررسید انقضا.
